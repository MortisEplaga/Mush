# Mush — содержание

Грибница с оптической сигнальной сетью: фотогифы, полые жилы, ассоциативные камеры, распределённое обучение и предсказание.

Mush воспринимает среду, передаёт сообщения светом и меняет связи по результатам своих действий. Местные сенсоры и ассоциативные камеры связаны живыми фотогифами. Между округами свет ведут полые воздушные жилы внутри ризоморфов, а станции на их концах переизлучают сигнал. Свечение дают грибные люциферазы и гидрофобины, синюю и фиолетовую вспышки — кальциевые фотопротеины с хромофором coelenterazine, кремнезёмную выстилку осаждает силикатин, а поток в жиле замыкают тургорные клапаны. Каждый модуль работает на собственном физическом пределе — оптики, кинетики, энергетики, — и эти пределы задают параметры сети.
